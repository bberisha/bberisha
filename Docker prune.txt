Daily Cleanup
=============

docker system prune -af --filter "until=$((30*24))h"

Cron it
=======

cd /etc/cron.daily
sudo nano docker-prune

#!/bin/bash
docker system prune -af --filter "until=$((30*24))h"


Change permission
=================

sudo chmod +x /etc/cron.daily/docker-prune

run-parts /etc/cron.daily
